# 00 — 입력 정리 (Organized Input)

> mobile-app-builder / **UX Mode** (ux-designer + qa-engineer)
> 출처: `plan.md` (2026-07-10 기획 확정본)

## 프로젝트

- **앱 이름(가칭)**: Campus-On
- **한 줄 소개**: 외국인 유학생이 입학부터 졸업까지 학교 생활에 필요한 정보를 한 곳에서
- **앱 유형**: 유틸리티 / 정보 안내 (Information & Guide)
- **대상 범위**: 특정 한 대학교 전용

## 확정 사양

| 항목 | 값 |
|------|-----|
| 플랫폼 | iOS + Android (Cross-platform) |
| 프레임워크 | **Flutter** |
| 지도 | **카카오맵 SDK** |
| 백엔드/DB | Firebase (Firestore) |
| 인증 | **비로그인 열람** (MVP) |
| 다국어 | **한국어 + 영어** (i18n / ARB) |
| 제약 | 1인 개발 · 1개월 · 예산 최대 $500 |

## MVP 범위 (이번 설계 대상)

1. **캠퍼스 지도 & 시설 안내** — 카카오맵 위 시설 좌표 오버레이, 시설 목록/상세/검색
2. **행정 절차 가이드** — 카테고리 틀 우선(콘텐츠는 자리표시자), 공통 상세 템플릿
3. **다국어(한/영)** — 모든 화면의 기반

### 행정 가이드 카테고리 틀 (6개)
- 입국·체류 (비자, 외국인등록증, 체류연장)
- 주거 (기숙사, 교외 주거)
- 생활 인프라 (은행, 휴대폰, 교통카드)
- 건강·보험 (건강보험, 보건소, 병원)
- 학교 행정 (수강신청, 증명서, 국제교류처)
- 긴급/도움 (긴급연락처, 사건사고 대응, 상담)

> 각 항목 상세는 통일 구조: **개요 → 준비물 → 단계 → 관련 링크/위치**

## 페르소나

- **교환학생 A** — 단기 체류, 빠른 적응·생활 정보 중심
- **학위과정 유학생 B** — 장기 체류, 행정·정착 정보 중심
- 공통 니즈: 영어 지원, 오프라인 접근성, 신뢰할 수 있는 최신 정보

## 이번 단계 목표 (1주차 UX)

정보 구조(IA) + 화면 구조 + 와이어프레임 + 디자인 시스템(토큰/컴포넌트) + 네비게이션/인터랙션.
접근성(A11y), 한/영 다국어 레이아웃, iOS HIG / Material 3 동시 고려.

## 범위 밖 (이번 설계에서 제외)

- 로그인/회원 기능, 푸시 알림, 커뮤니티/Q&A (Phase 2+)
- 실제 행정 콘텐츠 텍스트 (틀만)
- 실제 코드 구현, API 연동, 스토어 메타데이터 (후속 단계)
