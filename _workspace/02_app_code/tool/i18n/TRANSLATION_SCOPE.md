## 학식 메뉴에 대해

지금 번역된 메뉴 줄은 **샘플 식단**의 것이다(화면에도 예시라고 안내한다). 학교 API가 붙은 뒤의 실제 식단은 번역돼 있지 않으며, 번역이 없는 줄은 한국어로 표시된다. 새 메뉴를 찾아 번역까지 잇는 절차는 `tool/i18n/menu_scan_test.dart` 주석에 적혀 있다.
