# 베트남어(vi) 용어·표기 기준

`lib/data/i18n/guides_vi.json`과 `lib/l10n/app_vi.arb`를 고칠 때 쓰는 기준 문서다. 베트남어 1~11차 번역과 후속 검토 반영(보고서 037~053)에서 실제 파일에 확정된 표기를 모았다.

- 대상: 행정 가이드 30개 1,597필드와 화면 문자열
- 상태: **초안** — 기존 번역을 다시 번역하거나 전수 재감사한 문서가 아니다.
- 이 문서를 고칠 때는 실제 JSON/ARB 표기와 어긋나지 않는지 함께 확인한다.

---

## 1. 표기 규칙

### 1.1 성조 부호와 문체

- 베트남어 성조 부호를 생략하지 않는다: `đăng ký`, `thị thực`, `cơ sở`.
- 사용자가 해야 할 일은 짧고 직접적인 문장으로 쓰되, 원문의 조건·예외·부정·불확실성을 확정 사실로 바꾸지 않는다.
- 같은 제도·기관·서류는 아래 용어표의 표기를 유지한다.
- 문서명·기관명은 첫 글자를 대문자로 쓰고, 일반명사는 문장 위치에 따라 소문자로 쓸 수 있다.

### 1.2 한국어 병기

- 현장에서 서류·기관·제도명을 보여 주거나 한국어 사이트·서식에서 찾아야 하는 용어는 **가이드별 첫 등장 1회** 한국어를 괄호로 병기한다.
- 이후 등장은 베트남어만 쓴다. 검색 별칭은 실제 검색을 위해 한국어 원문을 별도로 남길 수 있다.
- 전화번호·URL·가이드 ID와 한국어 주소는 표기까지 원문 그대로 둔다.

### 1.3 캠퍼스명

| 한국어 | 기본 표기 | 가이드별 첫 등장 |
|---|---|---|
| 승학캠퍼스 | `cơ sở Seunghak` | `cơ sở Seunghak (승학캠퍼스)` |
| 부민캠퍼스 | `cơ sở Bumin` | `cơ sở Bumin (부민캠퍼스)` |
| 구덕캠퍼스 | `cơ sở Gudeok` | `cơ sở Gudeok (구덕캠퍼스)` |

- 문장·라벨 첫머리에서는 `Cơ sở`로 쓴다.
- 캠퍼스 이름 앞에 `khuôn viên`을 쓰지 않는다. 일반명사 “교내” 의미의 `khuôn viên`은 가능하다.
- 생활관명·관명·주소의 `Seunghak 1`, `Seunghak 2`, `Bumin`, `Gudeok`, `Bumin-…`은 캠퍼스 병기 대상이 아니다.
- 근거: 051·052, `test/campus_name_vi_test.dart`.

### 1.4 숫자·금액·기한

- 값은 바꾸지 않고 베트남어 자릿수 표기를 쓴다: `10.000.000 won`, `35.000 won`, `1.000.000 won`, `50.000 USD`.
- 날짜는 `ngày 1 tháng 1 năm 2025`처럼 쓸 수 있다. 전화번호·URL·가이드 ID는 원문 그대로다.
- 포함 경계를 분명히 한다: 이상=`từ N trở lên`/`ít nhất N`, 미만=`chưa đủ N`, 마감일까지=`chậm nhất vào…`, 이후(기준 시각 포함)=`từ… trở đi`.
- 학점 한도 감축은 `giảm N tín chỉ`이며 `hạn chế N tín chỉ`(최대 N학점)로 쓰지 않는다.
- 학점은 숫자 뒤에 `tín chỉ`를 붙인다. 시간·주·일은 각각 `giờ`·`tuần`·`ngày`를 쓰고, 하한·상한은 위 경계 표현과 결합한다: `từ 4 tuần trở lên`, `chưa đủ 3 năm`, `chậm nhất vào ngày 25`.
- 근거: 038·053, `TRANSLATION_GUIDE.md` 8절.
