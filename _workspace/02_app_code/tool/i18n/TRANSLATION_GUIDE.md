# 가이드·화면 번역 작성 규칙 (중국어 간체 zh / 베트남어 vi)

이 폴더의 파일은 번역 작업의 공통 기준이다. 한국어·영어는 Dart 카탈로그에 그대로 두고,
번역은 언어별 JSON 파일 하나에만 쓴다. 두 번역자가 같은 파일을 건드리지 않는다.

## 1. 담당 파일

| 언어 | 화면 문자열 | 가이드 본문 |
|---|---|---|
| 중국어 간체 (A 클로드) | `lib/l10n/app_zh.arb` | `lib/data/i18n/guides_zh.json` |
| 베트남어 (B 코덱스) | `lib/l10n/app_vi.arb` | `lib/data/i18n/guides_vi.json` |

그 밖의 파일(Dart, seed, 상대 언어 파일)은 읽기만 한다. 코드·생성 파일은 리드가 담당한다.

## 2. 원문

- 가이드 원문: `tool/i18n/source/<guide-id>.json`
  - `fields` 아래에 번역할 항목이 경로별로 들어 있다.
  - `ko`가 번역 기준이고 `en`은 참고 번역이다. 목록에는 `count`(항목 수)가 붙어 있다.
- 화면 문자열 원문: `lib/l10n/app_ko.arb`(기준) · `lib/l10n/app_en.arb`(참고, 151키)
- 진행 현황: `python tool/i18n/i18n_tool.py status`

## 3. 가이드 번역 파일 형식

`lib/data/i18n/guides_zh.json` (vi도 같은 형식) — 가이드 id → 필드 경로 → 번역:

```json
{
  "arc-issue": {
    "title": "外国人登录证(ARC)签发",
    "checklist": ["...", "..."],
    "sections[0].title": "...",
    "sections[1].notes[0].lines": ["...", "..."],
    "links[2].description": "...",
    "phrases[0].text": "..."
  }
}
```

- 경로는 `source/<id>.json`의 `fields` 키를 그대로 쓴다. 새 경로를 만들지 않는다.
- 목록(list)은 원문과 항목 수가 같아야 한다. 한 줄을 합치거나 나누지 않는다.
- 번역하지 않은 항목은 아예 쓰지 않는다(그러면 영어 → 한국어 순으로 표시된다).
- `phrases[n].text`는 직원에게 보여 줄 **한국어 문장의 뜻**이다. 한국어 문장 자체는 화면에 그대로 남으므로 번역하지 않는다.
- UTF-8, BOM 없음.

## 4. 화면 문자열(.arb) 형식

```json
{
  "@@locale": "zh",
  "home_title": "...",
  "search_hint": "..."
}
```

- 키 이름은 영어 파일과 똑같이 쓴다. 메타(`@키`) 블록은 넣지 않아도 된다.
- ICU 자리표시자(`{count}`, `{price}`, `{n}` 등)와 줄바꿈(`\n`)은 그대로 둔다.
- 채우지 않은 키는 영어가 표시된다.

## 5. 번역 규칙 (공통)

1. 금액·기한·자격 조건·예외·부정 표현·전화번호·URL·가이드 ID를 바꾸지 않는다. 숫자와 링크는 원문 그대로 남긴다.
2. 「확인 필요」, 기관별 차이, 추정 표현은 확정된 사실로 바꾸지 않고 그대로 옮긴다.
3. 원문에 없는 기관명·절차·조건을 보태지 않는다.
4. 문장은 자연스럽고 간결하게. 다만 조건과 예외를 생략하지 않는다.
5. 행정 용어는 한 파일 안에서 같게 쓰고, 처음 나올 때 한국어 원어를 괄호로 병기한다.
   - 중국어 예: `外国人登录证(외국인등록증)`
   - 베트남어 예: `thẻ đăng ký người nước ngoài(외국인등록증)`
6. 중국어는 간체자만 쓴다. 베트남어는 성조 부호를 정확히 쓴다(성조 없는 검색은 코드가 따로 처리하므로 화면 문구에서 성조를 빼지 않는다).
7. 용어 통일표(한국어 → 번역어)를 보고서에 남긴다.

## 7. 작업 단위

- 가이드는 3~5개 묶음으로 끝낼 때마다 보고한다. 30개를 다 끝낼 때까지 미루지 않는다.
- 초안과 독립 검토 완료본을 구분한다. 자기 번역을 스스로 확인한 것은 검토 완료가 아니다.

## 8. 숫자·단위 표기 (2026-09-25 추가)

- **값은 유지하고, 표기는 그 언어 방식으로 쓴다.** 한국어 수량 단위(`1천만원`, `100만 원`, `5만 달러`, `2024년 5월 2일`)를 번역문에 그대로 남기지 말고 해당 언어의 숫자·통화·날짜 표기로 옮긴다.
  - 베트남어 예: `10.000.000 won`, `1.000.000 won`, `50.000 USD`, `ngày 2 tháng 5 năm 2024`
  - 중국어 예: `1000万韩元`, `100万韩元`, `5万美元`, `2024年5月2日`
- 검증기는 자리 구분 기호를 무시하고 **숫자 값**만 비교하므로 위 표기가 통과한다. 값 자체(금액·기한·비율)는 절대 바꾸지 마라.
- 전화번호·URL·가이드 ID는 표기까지 원문 그대로 둔다.
