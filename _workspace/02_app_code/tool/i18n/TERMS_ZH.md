# 중국어 간체(zh) 용어·표기 기준

`lib/data/i18n/guides_zh.json`과 `lib/l10n/app_zh.arb`를 고칠 때 쓰는 기준 문서다. 1~12차 번역(보고서 025~036)과 검토 지적 반영(037~039)에서 실제로 확정해 **파일에 이미 적용돼 있는 표기**를 모았다. 새 문장을 쓰거나 기존 문장을 고칠 때 여기 있는 표기를 그대로 쓰면 파일 안에서 용어가 갈리지 않는다.

- 대상: 가이드 30개 1,597필드 + 화면 문자열 151키
- 규모: 표기 규칙 11항 · 용어표 9분류 **339행**(「한국어」열 항목을 ` / `로 나눈 개수 636) · 미결정 표기 7건
  - 계수 정정(042): 02/040은 336행·632항목으로 적었으나 실제는 337행·634항목이었다(조사 04/024 지적). 여기에 042에서 「재외국민 주민등록증」 1행, 043에서 「언어 저장 실패 안내」 1행을 더해 **339행·636항목**이 됐다. 중복 행·빈 행은 없다(한국어 열 중복 0).
- 상태: **초안** — 문서 자체는 독립 검토를 받지 않았다. 표기의 근거는 각 행의 「근거」 열이 가리키는 보고서다.
- 이 문서를 고칠 때는 `guides_zh.json`도 같이 고쳐 실제 파일과 어긋나지 않게 한다.

## 1. 표기 규칙

### 1.1 간체자만 쓴다

번체 전용 글자는 쓰지 않는다(파일 전체 자동 점검 결과 0건).

### 1.2 캠퍼스는 로마자 + `校区`, 가이드마다 첫 등장 1회만 한국어 병기

| 한국어 | 표기 | 첫 등장 병기 |
|---|---|---|
| 승학캠퍼스 | `Seunghak校区` | `Seunghak校区(승학캠퍼스)` |
| 부민캠퍼스 | `Bumin校区` | `Bumin校区(부민캠퍼스)` |
| 구덕캠퍼스 | `Gudeok校区` | `Gudeok校区(구덕캠퍼스)` |

- 한자 추정 표기(`承学`·`釜民`·`富民`·`九德`·`承鹤`)는 **쓰지 않는다**. 동아대 공식 중국어 표기를 공개 자료로 확인할 수 없어 로마자로 정했다(근거: 028·030, 리드 결정).
- 병기는 **가이드마다 캠퍼스별 1회**다. 같은 가이드에서 두 번째 이후로 나올 때는 로마자만 쓴다.
- 관(館) 이름도 캠퍼스 요소를 로마자로 쓴다: `Seunghak1馆`·`Seunghak2馆`·`Bumin馆`·`Gudeok馆`·`Bumin图书馆`.
- 지도 화면의 캠퍼스 칩(`map_campus_seunghak`·`_gudeok`·`_bumin`)은 **로마자만**(`Seunghak`·`Gudeok`·`Bumin`) — 3분할 토글이라 병기하면 칩 폭이 두 배가 된다.
- 회귀 테스트 `test/campus_name_zh_test.dart`가 이 규칙(한자 금지·칩 로마자·가이드별 병기 1회)을 검사한다.

### 1.3 괄호: 비중국어 내용은 반각 `( )`, 중국어 부가 설명은 전각 `（ ）`

- 반각 `( )` — 한국어 병기, 로마자·약어, 비자·자격 코드, 전화번호, 학기·날짜 코드, 건물 코드.
  예: `外国人登录证(외국인등록증, ARC)` · `留学(D-2)` · `(E-1~E-7等)` · `学生会馆(Q)` · `(2025-2学期)` · `(051-200-6447)`
- 전각 `（ ）` — 중국어로 쓴 부가 설명·예시·조건.
  예: `（不含插班）` · `（含假日）` · `（周六·公休日除外）` · `（以KT为准）`
- 중국어 설명 안에 한국어 병기가 들어가면 전각 안에 반각을 넣는다:
  `（研究课程等为研究生证明书(연구생증명서)）`
- 예외로 둔 곳(의도적):
  - `「(区号)120」` — 전화 다이얼 표기 자체가 원문 형식이다(`(지역번호)120`).
  - `(1350，劳动门户申诉)` — 전화번호로 시작하는 원문 괄호(`(1350, 노동포털 진정)`).
- 괄호 안이 **로마자 고유명칭**으로 시작하면 내용이 비중국어이므로 반각으로 쓴다(조사 04/024 반영):
  `(Seunghak校区)` · `(Bumin校区)` · `(Gudeok校区)` · `(Bumin馆)` · `(Seunghak1馆 · Seunghak2馆)`
  한자 고유명칭으로 시작하는 열거는 중국어 내용으로 보아 전각으로 둔다: `（翰林 · Bumin · 法学图书分馆）` · `（翰林 · Bumin · Gudeok）`
- 현재 파일 상태: 반각 246곳 · 전각 350곳(042에서 로마자 괄호 7곳을 전각→반각으로 고친 뒤).

### 1.4 「등록」계열은 `登录`, 「등기」와 "정보를 등록하다"는 `登记`

- **제도·서류·번호·사항**의 등록 → `登录`
  `外国人登录证`(외국인등록증) · `外国人登录`(외국인등록) · `外国人登录号码`(외국인등록번호) · `外国人登录事项变更申报`(외국인등록사항 변경신고) · `外国人登录事实证明`(외국인등록 사실증명) · `居民登录`(주민등록) · `海外韩国国民居民登录证`(재외국민 주민등록증) · `移动外国人登录证`(모바일 외국인등록증)
- **부동산 등기(등기)** → `登记`: `登记事项证明书`(등기사항증명서) · `登记簿`(등기부) · `登记所`(등기소) · `承租权登记命令`(임차권등기명령)
- **"정보를 등록하다 / 명의로 등록되어 있다" 같은 행위·상태** → `登记`: `登记英文姓名`(영문 성명 등록) · `以本人名义登记`(본인 명의로 등록) · `登记年龄信息`(연령 정보 등록) · `入住登记`(입사등록) · `已登记的地址`(등록된 주소)
  → 중국어 `登录`은 "로그인"으로 읽히므로 동사로는 쓰지 않는다.
- 관용상 `登记`를 쓰는 제도어 1건: `登记残疾人`(등록 장애인).

### 1.5 한국어 병기는 「가이드마다 첫 등장 1회」

행정 용어·서류명·제도명은 그 가이드에서 처음 나올 때만 `중국어(한국어)`로 병기하고 이후에는 중국어만 쓴다. 같은 용어를 한 가이드에서 두 번 병기하지 않는다.

- **화면 문자열(`app_zh.arb`)의 라벨·부제·탭에는 병기하지 않는다**(043). 320dp·글자 200% 화면에서 병기가 폭을 두 배로 늘리고, 같은 용어의 병기는 가이드 본문에 이미 있다.
  예: `guide_categorySummary_immigration`을 `签证·外国人登录(외국인등록)·停留延长(체류연장)`(46폭) → `签证·外国人登录·停留延长`(24폭)으로 고쳤다.
  본문 성격의 긴 문자열(`settings_about_body`·`settings_dataSource_body`)은 폭에 여유가 있어 기존 병기를 유지한다.

### 1.7 숫자·단위 (TRANSLATION_GUIDE 8절)

- 값은 유지하고 표기는 중국어 방식으로: `1천만원`→`1000万韩元`, `35,000원`→`35,000韩元`, `5만 달러`→`5万美元`, `6천만원`→`6000万韩元`, `1억 3,500만원`→`1亿3500万韩元`, `2024년 5월 2일`→`2024年5月2日`.
- 분수는 숫자로: `3분의 2`→`2/3`, `2분의 1`→`1/2`, `6분의 5`→`5/6`, `20분의 1`→`1/20`, `3분의 1`→`1/3`.
- 검증기가 숫자 값을 대조하므로 `1인 가구`→`1人家庭`, `제3자`→`第三方(제3자)`처럼 숫자를 지우지 않는다.
- 법조문: `제88조의2`→`第88条之2`, `제6조제3항`→`第6条第3款`(항=款).

### 1.10 고유명사 표기 우선순위 (보완: 조사 04/024)

공식 중국어 명칭이 없을 때 이 파일이 실제로 따르는 순서다.

1. **공식·관용 중국어 명칭이 있으면 그것을 쓴다** — `出入境·外国人厅`(출입국·외국인청) · `政府24`(정부24) · `健康保险审查评价院`(건강보험심사평가원).
2. **공식 명칭이 없고 사용자가 현장·검색에서 그 이름을 그대로 써야 하면 한국어 원문을 유지한다** — 주소 `부산 사하구 낙동대로550번길 37`, 브랜드·서비스 `이즐(캐시비)`·`HiKorea`, 학교 시스템 메뉴 경로, 교과목명(§1.6).
3. **학교 안내·건물 코드에 로마자가 이미 쓰이면 로마자 + 중국어 단위어** — `Seunghak校区` · `Bumin馆` · `Gudeok馆`(§1.2). 한자 음역(`釜民`·`承学` 등)은 만들지 않는다.
4. **한자로 옮겨도 뜻이 흔들리지 않는 이름만 의미역으로 옮긴다** — `翰林图书馆` · `石堂全球宿舍` · `全球人才馆`. 근거가 없는 의미역은 §3에 「확인 대기」로 남긴다.

- 한 가이드 안에서 같은 대상을 2·3·4번 방식으로 섞어 쓰지 않는다.
- 새 고유명사가 나왔을 때 1~3번을 적용할 근거가 없으면 4번으로 밀지 말고 §3에 적는다.
