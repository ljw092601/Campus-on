# 동아메이트 데이터 입력 안내

이 문서는 학사일정, 식당 정보, 학식 식단을 Google Sheets에서 입력하고 게시하는 관리자를 위한 안내입니다.

## 처음 한 번 준비하기

1. 개발자가 전달한 관리자용 Google Sheets를 엽니다.
2. 상단 메뉴에 `동아메이트`가 보이는지 확인합니다.
3. 처음 사용하는 문서이거나 양식이 바뀌었다는 안내를 받았다면 `동아메이트 → 시트 초기화`를 누릅니다.
4. 권한 승인 화면이 나오면 지정된 관리자 Google 계정으로 승인합니다.
5. `학사일정`, `식당`, `학식`, `예시`, `안내` 탭이 만들어졌는지 확인합니다.

헤더 행과 숨김 식별자 열은 수정하지 마세요. 메뉴가 없거나 권한 오류가 나면 개발자에게 연락하세요.

메뉴 항목:

| 메뉴 | 하는 일 |
|---|---|
| 시트 초기화 | 탭·헤더·드롭다운을 만들거나 정비합니다. 옛 학식 양식이면 새 양식으로 옮깁니다. 입력한 데이터는 지우지 않습니다. |
| 학사일정 동기화 | `학사일정` 탭 전체를 앱에 반영합니다 (시트에 없는 일정은 삭제). |
| 학식 동기화 | `학식` 탭의 식당·날짜 그룹을 앱에 반영합니다. |
| 식당 동기화 | `식당` 탭 전체를 앱에 반영합니다 (시트에 없는 식당은 삭제). |

## 학사일정 입력하기

1. `학사일정` 탭을 엽니다.
2. 한 일정당 한 행을 사용합니다.
3. `시작일`을 날짜로 입력합니다.
4. 기간 일정이면 `종료일(선택)`을 입력합니다. 하루 일정이면 비워 둡니다.
5. `일정명(국문)`과 `일정명(영문)`을 모두 입력합니다.
6. `분류`는 드롭다운에서 학사, 수강, 시험, 휴일, 졸업 중 하나를 고릅니다.
7. `동기화 결과`는 직접 입력하지 않습니다.

`event_id` 열은 숨겨져 있습니다. 처음 동기화할 때 자동 생성되며 일정 이름을 고쳐도 유지됩니다. 열을 다시 표시하거나 값을 복사·삭제·변경하지 마세요.

## 학사일정 게시하기

1. 입력 내용을 다시 확인합니다.
2. `동아메이트 → 학사일정 동기화`를 누릅니다.
3. 오류가 한 행이라도 있으면 전체 게시가 중단됩니다. 빨간색 `동기화 결과` 셀의 이유를 고친 뒤 다시 실행합니다.
4. 기존 앱에는 있지만 현재 시트에는 없는 일정이 있으면 삭제 예정 목록이 표시됩니다.
5. 목록이 의도한 삭제인지 확인합니다. 맞으면 `예`, 예상하지 못한 삭제면 `아니요`를 누르고 시트를 확인합니다.
6. 완료 창에서 게시 수와 삭제 수를 확인합니다.

학사일정에서 행을 지운 뒤 동기화하면 해당 일정은 앱에서도 삭제됩니다. 실수로 게시했다면 파일 → 버전 기록 → 버전 기록 보기에서 이전 시트 상태를 복원하고 다시 동기화하세요.

## 식당 탭 관리하기

`식당` 탭은 앱에 보이는 식당 목록입니다. `학식` 탭의 `식당` 드롭다운은 이 탭의 `이름(국문)` 열을 그대로 보여 주므로, 식당을 추가하거나 이름을 바꾸면 학식 탭에서도 바로 고를 수 있습니다. 처음 초기화하면 아래 8곳이 채워집니다.

|---|---|---|---|---|---|---|---|
| seunghak-faculty | 교수회관 식당 | Faculty Hall Cafeteria | 승학 | 11:40-13:30 | 점심만 운영 | s08 | 1 |

열별 입력 규칙:

- `식당ID`: 영문 소문자·숫자·하이픈(-)만 사용합니다 (예: `seunghak-student`). 다른 식당과 같은 ID를 쓸 수 없습니다. **한 번 게시한 식당의 ID는 바꾸지 마세요.** ID를 바꾸면 앱에서는 "옛 식당 삭제 + 새 식당 추가"로 처리되어 옛 ID로 게시한 식단이 보이지 않게 됩니다. 이름만 바꾸려면 `이름(국문)`·`이름(영문)` 열만 고칩니다.
- `이름(국문)`: 필수이며 다른 식당과 같은 이름을 쓸 수 없습니다 (학식 탭이 이 이름으로 식당을 고릅니다). 이름을 바꾸면 이미 입력한 `학식` 탭의 식당 칸도 새 이름으로 바꿔야 합니다.
- `이름(영문)`: 필수.
- `캠퍼스`: 드롭다운에서 승학/구덕/부민 중 하나.
- `운영시간`: `09:00-09:30, 10:00-14:30, 15:00-16:30`처럼 `시작-종료` 구간을 쉼표로 나열합니다. 쉬는 시간은 구간 사이의 빈 시간으로 표현됩니다. 각 구간은 시작이 종료보다 빨라야 하고 구간끼리 겹치면 안 됩니다. 학교가 운영시간을 공개하지 않으면 비워 두고 `운영 비고`에 적습니다.
- `운영 비고(국문)`/`운영 비고(영문)`: 앱에 그대로 보이는 짧은 안내입니다 (예: "천원의아침밥 09:00부터 선착순"). 선택 사항입니다.
- `지도 건물ID`: 캠퍼스 지도의 건물 코드(예: `s02`). 모르면 비워 둡니다. 개발자에게 코드를 확인하세요.
- `표시 순서`: 같은 캠퍼스 안에서 앱에 보이는 순서(작을수록 위). 0~9999 정수.
- `동기화 결과`: 직접 입력하지 않습니다.

식당을 없애려면 행을 삭제하고 `식당 동기화`를 실행합니다. 확인창에 삭제될 식당의 이름과 ID가 표시됩니다.

## 식당 게시하기

1. `동아메이트 → 식당 동기화`를 누릅니다.
2. 오류가 한 행이라도 있으면 전체 게시가 중단됩니다. 빨간색 `동기화 결과` 셀의 이유를 고친 뒤 다시 실행합니다.
3. 시트에 없는 식당이 앱에 있으면 삭제 예정 목록이 표시됩니다. 의도한 삭제면 `예`, 아니면 `아니요`를 누르고 시트를 확인합니다.
4. 식당을 새로 추가했다면 학식을 입력하기 전에 먼저 식당을 게시하세요. 식당이 게시되지 않으면 그 식당의 식단도 앱에 보이지 않습니다.

## 학식 입력하기

`학식` 탭의 한 행은 **한 식당, 한 날짜의 메뉴 묶음 하나**(시간대 × 유형)입니다. 같은 식당·같은 날짜에 여러 묶음이 있으면 묶음마다 한 행씩 추가합니다.

| 날짜 | 식당 | 시간대 | 유형 | 메뉴 | 가격 | 비고 | 상태 |
|---|---|---|---|---|---|---|---|
| 2026-10-13 | 교수회관 식당 | 점심 | 정식 | 제육볶음⏎미역국⏎밥⏎배추김치 | 7000 | 셀프바 | 게시 |
| 2026-10-13 | 학생회관 식당 | 아침 | 천원의아침밥 | 훈제오리솥밥 | 1000 | 09:00부터 선착순 | 게시 |
| 2026-10-13 | 학생회관 식당 | 종일 | 정식 | 돈육김치찌개⏎계란말이⏎밥⏎깍두기 | 6000 | | 게시 |
| 2026-10-13 | 학생회관 식당 | 종일 | 일품 | 국밥 6000⏎돈까스 7500⏎연어포케 9000 | | | 게시 |
| 2026-10-13 | 학생회관 식당 | 종일 | 양분식 | 김밥 3500⏎핫도그 2500 | | | 게시 |
| 2026-10-14 | 부민 교직원 식당 | | | | | | 휴무 |

(⏎ = 셀 안 줄바꿈, Windows `Alt+Enter` / Mac `Cmd+Enter`. 더 많은 예시는 `예시` 탭에 있습니다.)

열별 입력 규칙:

1. `날짜`: 달력에서 날짜를 고릅니다.
2. `식당`: 드롭다운에서 고릅니다. 목록은 `식당` 탭의 `이름(국문)`입니다.
3. `시간대`: 아침 / 점심 / 저녁 / 종일. 식당이 쉬는 시간을 두고 계속 운영하는 경우(학생회관·도서관 식당)는 `종일`을 씁니다.
4. `유형`: 메뉴 묶음의 종류입니다.
   - `정식`: 한 식판 가격이 하나인 메뉴. `가격` 열에 가격을 적고, 메뉴 항목에는 가격을 적지 않습니다.
   - `천원의아침밥`: `가격` 열에 `1000`을 적고 메뉴 항목에는 가격을 적지 않습니다.
   - `일품`: 메뉴마다 가격이 다른 단품(국밥·돈까스·포케 등). `가격` 열은 비우고 각 항목 끝에 가격을 적습니다.
   - `양분식`: 김밥·핫도그 같은 분식. `일품`과 같은 방식으로 적습니다.
5. `메뉴`: 항목을 **줄바꿈 또는 쉼표**로 구분합니다. 항목 끝에 숫자를 붙이면 그 항목의 가격이 됩니다. `7500`, `7,500`, `7,500원` 모두 됩니다 (예: `돈까스 7,500원`). 가격 없이 이름만 적어도 됩니다.
6. `가격`: 정식·천원의아침밥만 적습니다 (원 단위 숫자, `7000` 또는 `7,000원`). 일품·양분식은 비워 둡니다.
7. `비고`: 선택. 앱에 그대로 보이는 짧은 안내입니다 (예: `셀프바`, `09:00부터 선착순`).
8. `상태`: 정상 게시는 `게시`. 휴무·게시취소는 아래를 참고하세요.
9. `동기화 결과`: 직접 입력하지 않습니다.

같은 식당·날짜 안에서 같은 **시간대+유형** 조합은 한 행만 쓸 수 있습니다. 같은 시간대에 `정식`과 `일품`을 나란히 두는 것은 괜찮습니다 (예: 점심 정식 한 행 + 점심 일품 한 행).

## 휴무 또는 게시취소 입력하기

휴무일을 알리려면 날짜와 식당을 입력하고 상태를 `휴무`로 고릅니다. 이 행의 시간대·유형·메뉴·가격·비고는 모두 비워 두며, 같은 날짜·식당에 다른 행을 만들지 않습니다.

이미 게시한 식단을 미등록 상태로 되돌리려면 날짜와 식당을 입력하고 상태를 `게시취소`로 고릅니다. 나머지 열은 비웁니다. 게시취소는 앱 데이터를 삭제하지 않고 "미등록" 상태로 전달합니다.

학식 행을 시트에서 삭제하는 것만으로는 기존 앱 데이터가 삭제되지 않습니다. 기존 게시를 내리려면 반드시 `게시취소` 상태의 행을 입력하고 동기화하세요.

## 주간 입력 팁

1. 지난주 블록(같은 식당들의 월~금 행)을 통째로 선택해 복사합니다.
2. 빈 행에 붙여 넣고 `날짜` 열만 이번 주 날짜로 바꿉니다. 날짜 셀 하나를 고친 뒤 아래로 끌어 채우면 빠릅니다.
3. 메뉴·가격·비고를 이번 주 내용으로 고칩니다. 바뀌지 않는 행(예: 천원의아침밥 행)은 그대로 둡니다.
4. 휴무일은 그 날의 식당 행을 지우고 `휴무` 행 하나로 바꿉니다.
5. `학식 동기화`를 누르고 모든 행이 초록색 `✅ 동기화됨`인지 확인합니다.
6. 처음 입력할 때는 `예시` 탭의 행을 복사해 시작하면 됩니다. `예시` 탭은 동기화되지 않으므로 그곳에 입력해도 앱에 올라가지 않습니다.

지난 주 행은 지우지 않아도 됩니다. 동기화는 날짜별로 문서를 덮어쓸 뿐이고, 지난 날짜 행이 남아 있으면 같은 내용을 다시 쓰기만 합니다. 다만 시트가 너무 길어지면 오래된 행은 정리하세요(앱의 과거 데이터는 그대로 남습니다).

## 학식 게시하기

1. `동아메이트 → 학식 동기화`를 누릅니다.
2. 도구가 같은 식당·날짜의 행을 한 그룹으로 묶습니다.
3. 그룹 안에 오류가 하나라도 있으면 그 그룹 전체가 게시되지 않습니다. 다른 정상 그룹은 게시됩니다.
4. 빨간색 `동기화 결과` 셀의 이유를 확인하고 수정합니다.
5. 초록색 `✅ 동기화됨`이 표시된 행은 게시 완료입니다.

## 옛 양식에서 바뀐 점 (2026-10 이전 시트를 쓰던 경우)

`시트 초기화`를 실행하면 옛 `학식` 탭(`날짜 | 식당 | 식사 | 메뉴 (쉼표로 구분) | 가격 | 상태`)이 자동으로 새 양식으로 바뀝니다.

- `식사` 열이 `시간대`가 됩니다 (조식→아침, 중식→점심, 석식→저녁).
- `유형` 열이 새로 생기고 기존 행은 모두 `정식`으로 채워집니다. 일품·양분식이었다면 유형을 바꾸고 가격을 항목 끝으로 옮기세요.
- `비고` 열이 새로 생깁니다 (비어 있음).
- 식당 이름이 `승학 학생식당 → 학생회관 식당`, `구덕 학생식당 → 구덕 제2캠퍼스 학생회관`으로 바뀝니다. `부민 학생식당`은 자동으로 바꾸지 못하므로 `국제관 식당` 또는 `부민 교직원 식당` 등으로 직접 고르세요.
- 정식은 가격이 필수이므로 가격이 비어 있던 행은 채워야 합니다.
- 옛 동기화 결과는 지워집니다. 내용을 확인한 뒤 `학식 동기화`를 다시 실행하세요.

## 자주 발생하는 오류

- `날짜 형식으로 입력하세요`: 셀을 지운 뒤 달력에서 날짜를 다시 선택합니다.
- `허용 목록에 없습니다`: 직접 타이핑하지 말고 드롭다운에서 값을 다시 선택합니다.
- `식당 '...'이 '식당' 탭에 없거나 그 행에 오류가 있습니다`: `식당` 탭에서 그 식당 행이 있는지, 빨간 오류가 없는지 확인합니다. 이름을 바꿨다면 학식 탭의 식당 칸도 새 이름으로 고릅니다.
- `식당 '...'이 '식당' 탭에 여러 번 있어 고를 수 없습니다`: `식당` 탭에서 같은 이름을 하나만 남깁니다.
- `정식은 가격 열이 필수입니다`: 정식·천원의아침밥 행의 `가격` 열을 채웁니다.
- `정식은 가격 열에 한 가격만 쓰고 메뉴 항목 끝에는 가격을 붙이지 마세요`: 항목 끝의 숫자를 지우고 `가격` 열에 한 가격만 적습니다.
- `일품은 가격 열을 비우고 필요하면 항목 끝에 가격을 적으세요`: `가격` 열을 비우고 `국밥 6000`처럼 항목 끝에 적습니다.
- `점심 정식이 N행과 중복됩니다`: 같은 식당·날짜에 같은 시간대+유형 행을 하나만 남깁니다.
- `메뉴 항목 '...'에 이름이 없습니다`: 숫자만 있는 항목에 메뉴 이름을 적습니다.
- `메뉴에 빈 항목이 있습니다`: 연속 쉼표, 빈 줄, 마지막의 불필요한 쉼표를 지웁니다.
- `같은 식당·날짜 그룹의 상태는 모두 같아야 합니다`: 해당 그룹의 모든 행을 게시로 맞추거나, 휴무/게시취소 한 행만 남깁니다.
- `휴무/게시취소 행에는 시간대·유형·메뉴·가격·비고를 입력하지 마세요`: 그 행의 나머지 열을 비웁니다.
- `운영시간 '...'은 HH:mm-HH:mm 형식이어야 합니다`: `11:40-13:30`처럼 적고, 여러 구간은 쉼표로 나눕니다.
- `운영시간 구간 ...이 겹칩니다`: 구간이 서로 겹치지 않게 고칩니다.
- `식당ID는 영문 소문자·숫자·하이픈(-)만 쓸 수 있습니다`: 대문자·공백·밑줄을 없앱니다.
- `다른 관리자가 이미 동기화하고 있습니다`: 진행 중인 작업이 끝난 뒤 다시 시도합니다.
- `Firestore REST 오류`: 내용을 반복 수정하지 말고 오류 메시지와 발생 시각을 개발자에게 전달합니다.

## 안전 수칙

1. 동기화 완료 창이 뜰 때까지 브라우저를 닫지 않습니다.
2. 두 관리자가 동시에 동기화하지 않습니다.
3. 학사일정·식당 삭제 확인 창에서는 목록을 반드시 확인합니다.
4. 게시한 식당의 `식당ID`는 바꾸지 않습니다.
5. 숨김 열, 헤더, 드롭다운 규칙을 변경하지 않습니다.
6. 서비스 계정 키나 비밀번호를 시트에 입력하지 않습니다.
7. 오류를 해결할 수 없으면 행을 임의로 삭제하지 말고 개발자에게 문의합니다.
