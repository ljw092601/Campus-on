# Campus-On — Flutter app (week 2)

App skeleton + campus map & facility features. Screens S1 (Home), S2 (Map),
S3 (Facility List), S4 (Facility Detail), S8 (Search). Guide (S5–S7),
Settings (S9), Favorites (S10) are route stubs for week 3.

## First-time setup

Native platform folders (`android/`, `ios/`) are generated by Flutter. They
were generated and verified on Flutter 3.44.6 (QA 라운드 2); regenerate only if
missing:

```bash
cd _workspace/02_app_code
flutter create --platforms=android,ios --project-name campus_on .   # only if android/ ios/ absent
flutter pub get         # also runs gen-l10n → lib/l10n/gen/app_localizations.dart
```

## Run (Kakao key injected, never committed)

The Kakao Maps JavaScript key is provided at run time — never hard-coded.

```bash
# Option A: inline
flutter run --dart-define=KAKAO_JS_KEY=your_js_key_here

# Option B: file (copy env.example.json → env.json, fill the key)
flutter run --dart-define-from-file=env.json
```

Without a key the Map screen renders its documented fallback ("Couldn't load
the map" + "Open facility list") instead of crashing.

### Kakao platform notes (verified against kakao_map_plugin 0.3.x)
`kakao_map_plugin` renders the Kakao Maps **JavaScript** SDK inside a WebView,
so it authenticates by the **JavaScript key** + a registered **Web 플랫폼**
site domain (NOT the Android/iOS native key or package name).

Kakao Developers console (https://developers.kakao.com):
1. 내 애플리케이션 → 애플리케이션 추가하기 → get the **JavaScript 키** (앱 키).
2. 앱 설정 → 플랫폼 → **Web 플랫폼 등록** → 사이트 도메인에 `http://localhost`.
   The plugin is initialized with `baseUrl: 'http://localhost'`
   (`lib/presentation/map/widgets/kakao_init.dart`), so the WebView origin the
   Kakao JS SDK sees is `http://localhost` — that exact domain must be allow-listed.
3. **제품 설정 → 카카오맵 → 활성화 설정 ON** ⚠️ *가장 놓치기 쉬운 필수 단계.*
   2024-12-01부터 신규 앱은 이 활성화가 없으면 sdk.js가 HTTP 403
   `{"errorType":"NotAuthorizedError","message":"App(...) disabled OPEN_MAP_AND_LOCAL service."}`
   를 반환하고 지도가 흰 화면이 된다(콘솔엔 `kakao is not defined`).
   빠른 자가진단: 호스트에서
   `curl -H "Referer: http://localhost" "https://dapi.kakao.com/v2/maps/sdk.js?appkey=<JS키>&autoload=false"`
   → **HTTP 200 + `window.kakao=...`** 본문이 나와야 정상.

Android (already applied in `android/app/src/main/AndroidManifest.xml`):
- `<uses-permission android:name="android.permission.INTERNET"/>`
- `android:usesCleartextTraffic="true"` on `<application>` (WebView loads http).

iOS: the plugin README requires ATS exceptions in `Info.plist` for the WebView
(add when the iOS run is set up).

## i18n

ARB sources live in `lib/l10n/app_en.arb` (template) and `app_ko.arb`.
`flutter gen-l10n` (auto-run on `pub get`) generates
`lib/l10n/gen/app_localizations.dart`. Key convention: `{screen}_{element}_{meaning}`.
