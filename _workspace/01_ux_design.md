# UX/UI 설계 문서 — Campus-On

> mobile-app-builder / UX Mode (ux-designer)
> 대상: Campus-On MVP · 외국인 유학생 캠퍼스 안내 앱
> 작성일: 2026-07-10 · 근거: `_workspace/00_input.md`

---

## 앱 개요

- **앱 이름**: Campus-On
- **플랫폼**: iOS + Android (Cross-platform / Flutter), 지도 = 카카오맵 SDK
- **핵심 사용자**: 2 페르소나
  - **교환학생 A** — 단기 체류, 빠른 캠퍼스 적응·생활 정보 중심. 영어 우선.
  - **학위과정 유학생 B** — 장기 체류, 행정·정착 절차 정보 중심. 한/영 병행.
- **핵심 가치 제안**: "외국인 유학생이 캠퍼스 시설과 행정 절차를 로그인 없이 한/영으로 즉시 찾는다."

### 설계 원칙 (제약 반영)
| 제약 | 설계 대응 |
|------|-----------|
| 1인 개발 · 1개월 · $500 | 화면 10개 이내, 컴포넌트 재사용 최대화, 커스텀 애니메이션 최소 |
| 비로그인 | 온보딩/인증 화면 없음, 즐겨찾기는 로컬 저장(디바이스) |
| 한/영 다국어 | 모든 문자열 ARB 키, 가변 길이 레이아웃, 하드코딩 텍스트 0 |
| 콘텐츠 자리표시자 | 행정 상세는 "구조 확정 + 더미 콘텐츠", 스키마만 견고하게 |
| 과설계 금지 | Firestore 읽기 전용 구조 가정, 서버 로직 없음 |

## 1. 정보 구조 (IA)

### 사이트맵

```
Campus-On (하단 탭 4개)
│
├── [탭1] 홈 (Home)
│     ├── 언어 전환 퀵액션
│     ├── 지도 바로가기 카드
│     ├── 시설 카테고리 6종 퀵칩 → 시설 목록(필터 적용)
│     ├── 행정 가이드 카테고리 6종 그리드 → 가이드 상세 목록
│     └── 통합 검색 진입
│
├── [탭2] 지도 (Map)
│     ├── 카카오맵 + 시설 마커 오버레이
│     ├── 카테고리 필터 칩(가로 스크롤)
│     ├── 지도/목록 토글
│     ├── → 시설 목록 (List View)
│     └── → 시설 상세 (하단 시트 → 전체 상세)
│
├── [탭3] 가이드 (Admin Guide)
│     ├── 행정 카테고리 6종 목록
│     ├── → 카테고리별 항목 목록
│     └── → 행정 상세 (개요→준비물→단계→관련링크/위치)
│           └── 관련 위치 → 지도 딥링크(마커 포커스)
│
├── [탭4] 설정 (Settings)
│     ├── 언어 전환 (한/영)
│     ├── 즐겨찾기 목록(로컬)
│     ├── 정보(About) / 데이터 출처 / 버전
│     └── 라이선스·문의
│
└── [모달/스택 공통]
      ├── 검색 (Search) — 시설+가이드 통합, 탭2·탭3·홈에서 진입
      └── 시설 상세 / 행정 상세 (스택 push, 딥링크 대상)
```

### 화면 계층 (Depth)
- 최대 깊이 3단계 준수: `탭 → 목록 → 상세`
- 어디서든 홈 복귀 가능(하단 탭 상시 노출)
- 상세 화면은 스택 push(탭바 유지 or 전체 화면 — 아래 네비 섹션 참조)

### 네비게이션 구조
- **패턴**: Bottom Tab Bar (4탭) + 탭별 Stack Navigator
- **탭 수 4개** 선정 근거: mobile-ux-patterns의 Tab Bar 권장(3–5개). 지도/가이드가 앱의 두 축이므로 각각 독립 탭. 검색은 탭이 아닌 공용 진입점(홈/지도/가이드 상단 검색바)으로 두어 탭 절약.

| 탭 | 라벨(ko/en) | 아이콘(개념) | 기본 화면 |
|----|-------------|--------------|-----------|
| 1 | 홈 / Home | home | HomeScreen |
| 2 | 지도 / Map | map-pin | MapScreen |
| 3 | 가이드 / Guide | list-checks | GuideCategoryScreen |
| 4 | 설정 / Settings | settings | SettingsScreen |

## 2. 화면 목록 & 와이어프레임

총 **10개 화면** (MVP 최소 구성). 상세는 목록에서 재사용되는 템플릿 2종(시설 상세 / 행정 상세)으로 통일.

| # | 화면 | 역할 | 유형 |
|---|------|------|------|
| S1 | 홈 (Home) | 진입·허브, 6+6 카테고리 관문 | 대시보드 |
| S2 | 지도 (Map) | 카카오맵 + 마커, 필터 | 지도 |
| S3 | 시설 목록 (Facility List) | 카테고리/검색 결과 리스트 | 리스트 |
| S4 | 시설 상세 (Facility Detail) | 단일 시설 정보 + 지도 | 상세 |
| S5 | 가이드 카테고리 (Guide Categories) | 행정 6분류 관문 | 그리드/리스트 |
| S6 | 가이드 항목 목록 (Guide Item List) | 카테고리 내 항목 | 리스트 |
| S7 | 행정 상세 (Guide Detail) | 개요→준비물→단계→링크/위치 | 상세 |
| S8 | 검색 (Search) | 시설+가이드 통합 검색 | 검색 |
| S9 | 설정 (Settings) | 언어·즐겨찾기·정보 | 리스트 |
| S10 | 즐겨찾기 (Favorites) | 로컬 저장 시설/가이드 | 리스트 |

> About/정보는 설정 하위의 정적 화면(경량)으로, 별도 카운트 없이 S9 스택 내 서브 스크린으로 처리.

### S1. 홈 (Home) — 진입 허브

- **목적**: 첫 진입 시 "지도로 갈지 / 행정 절차를 볼지"를 3초 안에 선택하게 함. 검색 관문.
- **주요 요소**: 상단 앱바(로고 + 언어 토글), 통합 검색바, 지도 바로가기 배너, 시설 카테고리 퀵칩(6), 행정 가이드 그리드(6).
- **인터랙션**: 검색바 탭 → S8. 카테고리 칩 탭 → S3(필터). 가이드 카드 탭 → S6.

```
┌──────────────────────────────┐
│ Campus-On            [KO|EN]  │ ← 앱바 + 언어토글
├──────────────────────────────┤
│  🔍  시설·행정 검색            │ ← 검색바(탭→S8)
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │  🗺  캠퍼스 지도 보기      │ │ ← 지도 배너(탭→S2)
│ │      가까운 시설 찾기 →    │ │
│ └──────────────────────────┘ │
│                              │
│ 시설 카테고리                 │
│ [건물][강의실][식당][도서관]  │ ← 퀵칩 6종(가로 스크롤)
│ [편의][기타]                  │ ← building/classroom/dining/
│                              │   library/amenity/etc
│                              │
│ 행정 가이드                   │
│ ┌────┐┌────┐┌────┐          │
│ │입국 ││주거 ││생활 │         │ ← 6 그리드(2×3)
│ │·체류││    ││인프라│         │
│ └────┘└────┘└────┘          │
│ ┌────┐┌────┐┌────┐          │
│ │건강 ││학교 ││긴급 │         │
│ │·보험││행정 ││·도움│         │
│ └────┘└────┘└────┘          │
└──────────────────────────────┘
│  [홈] [지도] [가이드] [설정]  │ ← 하단 탭바
└──────────────────────────────┘
```

- **상태**:
  - Loading: 배너/그리드 스켈레톤(카테고리는 정적이라 즉시, 시설 카운트만 지연 가능).
  - Empty: 시설 데이터 0건 → "표시할 시설 정보가 아직 없어요" 인라인.
  - Error: 카테고리는 하드코딩이라 항상 노출; 원격 카운트 실패 시 배지만 숨김(치명 아님).

### S2. 지도 (Map) — 카카오맵 + 시설 마커

- **목적**: 현재 위치/캠퍼스 기준 시설을 지도에서 탐색. 카테고리 필터로 마커 좁히기.
- **주요 요소**: 카카오맵 뷰, 상단 검색바, 카테고리 필터 칩(가로 스크롤), 우하단 "내 위치" FAB, 지도/목록 토글, 마커 탭 시 하단 미니 시트.
- **인터랙션**: 마커 탭 → 하단 Peek 시트(이름·카테고리·거리·[상세] 버튼) → 스와이프 업 or [상세] → S4. 목록 토글 → S3.

```
┌──────────────────────────────┐
│ ← 지도            🔍  [목록↔]  │ ← 앱바(검색/토글)
├──────────────────────────────┤
│ [전체][건물][식당][도서관]▸   │ ← 필터칩(가로 스크롤)
├──────────────────────────────┤
│                              │
│        📍        📍          │
│            ★(선택)            │ ← 카카오맵 + 마커
│    📍                 📍     │
│              📍              │
│                       ┌───┐  │
│                       │ ⊚ │  │ ← 내 위치 FAB
│                       └───┘  │
├──────────────────────────────┤
│ ▁▁▁▁ (드래그 핸들) ▁▁▁▁       │
│ 중앙도서관        · 도서관     │ ← Peek 시트
│ 📍 120m         [상세 보기 →] │
├──────────────────────────────┤
│  [홈] [지도] [가이드] [설정]  │
└──────────────────────────────┘
```

- **상태**:
  - Loading: 지도 타일 로딩 중 반투명 오버레이 + 스피너(0.5s 이후).
  - Empty: 필터 결과 마커 0 → 지도 위 토스트 "이 카테고리의 시설이 없어요".
  - Error: 카카오맵 로드 실패 → 전체 화면 폴백("지도를 불러오지 못했어요 [다시 시도]") + 시설 목록으로 대체 이동 CTA.
  - Permission: 위치 권한 거부 → 캠퍼스 중심 좌표로 폴백, "내 위치 FAB" 탭 시 권한 재요청 안내.

### S3. 시설 목록 (Facility List)

- **목적**: 마커 대신 스캔하기 좋은 리스트. 검색 결과/카테고리 필터 결과 공용.
- **주요 요소**: 상단 검색바, 필터 칩, 정렬(거리순/이름순), 리스트 아이템(아이콘·이름·카테고리·거리·즐겨찾기 별).
- **인터랙션**: 아이템 탭 → S4. 별 아이콘 탭 → 즐겨찾기 토글(로컬). Pull-to-refresh.

```
┌──────────────────────────────┐
│ ← 시설 목록       🔍  [지도↔]  │
├──────────────────────────────┤
│ [전체][건물][식당]▸  정렬:거리▾│
├──────────────────────────────┤
│ 🏛  중앙도서관            ☆   │
│     도서관 · 120m            │
│ ────────────────────────     │
│ 🍚  학생회관 식당         ★   │
│     식당 · 210m              │
│ ────────────────────────     │
│ 🏢  공학관 3호관          ☆   │
│     건물 · 340m              │
│ ────────────────────────     │
│ ☕  카페 온               ☆   │
│     편의시설 · 90m           │
├──────────────────────────────┤
│  [홈] [지도] [가이드] [설정]  │
└──────────────────────────────┘
```

- **상태**:
  - Loading: 리스트 아이템 스켈레톤 6줄.
  - Empty: "검색/필터에 맞는 시설이 없어요" 일러스트 + [필터 초기화] CTA.
  - Error: "목록을 불러오지 못했어요 [다시 시도]" 배너.

### S4. 시설 상세 (Facility Detail)

- **목적**: 단일 시설의 위치·운영정보·연락처 제공, 지도 연결.
- **주요 요소**: 헤더(이미지 또는 카테고리 컬러 배너), 이름(ko/en), 카테고리 배지, 미니 지도(카카오 static/embed), 주소, 운영시간, 전화, 설명, 하단 고정 [지도에서 보기] / [전화].
- **인터랙션**: [지도에서 보기] → S2 딥링크(해당 마커 포커스). 전화 탭 → 다이얼. 별 → 즐겨찾기.

```
┌──────────────────────────────┐
│ ←                       ☆    │ ← 뒤로/즐겨찾기 (공유는 Phase 2 이월)
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │  [카테고리 컬러 배너/사진] │ │
│ └──────────────────────────┘ │
│ 중앙도서관                    │ ← Title(ko)
│ Central Library    · 도서관   │ ← subtitle(en)+배지
│                              │
│ ┌── 미니 지도 (카카오) ──┐    │
│ │        📍            │     │ ← 탭→S2 딥링크
│ └──────────────────────┘     │
│ 📍 서울시 …  캠퍼스 A동 옆    │
│ 🕐 09:00–22:00 (평일)         │
│ ☎  02-000-0000               │
│                              │
│ 소개                          │
│ 열람실, 그룹스터디룸, …       │
├──────────────────────────────┤
│ [ 지도에서 보기 ]  [ ☎ 전화 ] │ ← 하단 고정 CTA
└──────────────────────────────┘
```

- **하단 CTA 반응형 규칙(A11y)**: 기본은 [지도에서 보기] / [전화] 가로 2버튼. **폰트 스케일 확대(예: 200%)로 두 버튼 라벨이 한 줄에 안 들어가면(각 버튼 최소 폭 미달) 세로 스택(위=지도, 아래=전화)으로 자동 전환**한다. 각 버튼 높이 ≥ 48dp 유지, 세로 전환 시에도 하단 고정. (Flutter `LayoutBuilder` + `textScaleFactor` 분기)
- **상태**:
  - Loading: 헤더+본문 스켈레톤.
  - Partial: 이미지 없음 → 카테고리 컬러 배너 대체. 전화/운영시간(`hours_ko`/`hours_en` 모두 없음) → 해당 행 숨김(빈 라벨 표시 금지).
  - Error: 상세 로드 실패 → "정보를 불러오지 못했어요 [다시 시도]" 전면.

---

### S5. 가이드 카테고리 (Guide Categories) — 탭3 기본

- **목적**: 행정 6분류 관문. 각 분류의 항목 수 표시.
- **주요 요소**: 상단 검색바, 6개 카테고리 리스트(아이콘·제목·설명·항목수·chevron).
- **인터랙션**: 행 탭 → S6.

```
┌──────────────────────────────┐
│ 행정 가이드           🔍       │
├──────────────────────────────┤
│ 🛂 입국·체류              5 › │
│    비자·외국인등록·체류연장    │
│ ────────────────────────     │
│ 🏠 주거                   3 › │
│    기숙사·교외 주거           │

│    은행·휴대폰·교통카드       │
│ ────────────────────────     │
│ 🏥 건강·보험              3 › │
│    건강보험·보건소·병원       │
│ ────────────────────────     │
│ 🎓 학교 행정              4 › │
│    수강신청·증명서·국제교류처  │
│ ────────────────────────     │

│    긴급연락처·사건사고·상담    │

│  [홈] [지도] [가이드] [설정]  │

## 3. 네비게이션 & 인터랙션

### 탭 ↔ 스택 구조
- 각 탭은 독립 Stack. 탭 재선택 시 해당 스택 루트로 pop-to-root.
- **상세 화면(S4/S7)의 탭바 처리**: 탭바 **유지**(딥링크·연속 탐색 위해). 단, 지도 상세(S4)의 미니 지도는 전체 화면 전환 없이 인라인.

### 핵심 이동 흐름
```
[지도 S2] ──마커 탭──▶ Peek 시트 ──[상세]──▶ [시설 상세 S4]
   ▲                                              │
   └──────────[지도에서 보기] 딥링크──────────────┘

[지도 S2] ◀──[목록↔지도 토글]──▶ [시설 목록 S3] ──탭──▶ [시설 상세 S4]

[가이드 S5] ──탭──▶ [항목 목록 S6] ──탭──▶ [행정 상세 S7]
                                              │
           관련 위치 카드 탭(relatedFacilityIds)    ▼
        [지도 S2: 마커 포커스 + 대표 Peek] ──[상세 보기]──▶ [시설 상세 S4]
```

### 딥링크 (행정 → 지도) — 계약 단일화
- 행정 상세 S7은 **`relatedFacilityIds: string[]`(복수)** 하나만 사용한다. 단수 필드·`?focus=단건`은 폐기.
- **목적지·파라미터 확정(유일 규칙)**: 위치 카드 탭 → 항상 **지도 탭(S2)** 으로 전환, 라우트 `/map?focus=<id1>,<id2>,...`.
  - 카메라: 전달된 마커들이 모두 보이도록 fitBounds(단건이면 해당 좌표로 이동).
  - 마커: 전달된 id 전부 selected 강조, **대표 1개(배열 첫 요소)의 Peek 시트 자동 오픈**.
  - 단건/복수 모두 **동일한 하나의 흐름**을 탄다(S4 직행 분기 없음). 사용자는 Peek 시트의 [상세 보기]로 S4에 진입.
- 앱 외부 딥링크(선택): `campuson://map?focus=<ids>`, `campuson://guide/{id}` (Phase 2 확장 여지, MVP는 앱 내부 라우팅만 구현).

### 제스처 (mobile-ux-patterns 준수)
| 제스처 | 위치 | 동작 |
|--------|------|------|
| Tap | 전역 | 선택/이동 (ripple/highlight 피드백 필수) |
| Edge swipe (뒤로) | iOS | 스택 pop (Android는 시스템 back/제스처 내비) |
| Swipe up/down | 지도 Peek 시트 | 시트 확장/축소 |
| Swipe left | 즐겨찾기 아이템 | 삭제 |
| Pull-to-refresh | 목록(S3/S6) | 데이터 갱신 |
| Pinch | 지도 | 줌 (카카오맵 기본) |
| 가로 스크롤 | 필터 칩/퀵칩 | 카테고리 스크롤 |

### 전환/애니메이션 (경량)
- 화면 전환: 플랫폼 기본(iOS slide, Android shared-axis). 커스텀 최소화(예산 고려).
- 시트: 표준 Draggable Bottom Sheet.
- Reduced motion 설정 시 전환을 페이드로 강등.

## 5. 다국어 (한국어 / 영어) 고려

### 텍스트 길이 가변 대응
- 영어가 한국어보다 30–50% 길어질 수 있음 → 고정 폭 금지, `Flexible`/`Expanded`/`softWrap` 사용.
- 버튼·칩: 최소 폭 + 좌우 패딩, 최대 2줄 `ellipsis` 허용. 아이콘+텍스트 칩은 아이콘 우선 유지.
- 리스트 제목 1줄 + subtitle 2줄까지 허용, 초과 시 `…`.
- 숫자/배지는 언어 무관 → 레이아웃 앵커로 활용.

### 언어 전환 UX
- 진입점 2곳: 홈 앱바 `[KO|EN]` 퀵토글 + 설정 라디오. 둘 다 즉시 반영(재시작 없음, `Locale` 갱신 → 위젯 리빌드).
- 최초 실행: 디바이스 로케일 감지 → ko/en 아니면 en 기본. 사용자 선택은 로컬 저장(SharedPreferences), 이후 우선.
- 지도 마커·시설명은 데이터의 `name_ko`/`name_en` 중 현재 로케일 필드 사용, 없으면 다른 언어로 폴백 + 원문 표기.

### 문자열 키 네이밍 컨벤션 (ARB)
- 규칙: `{screen}_{element}_{meaning}` (lowerCamel), 파라미터는 ICU.
- 예시:
```

home_section_facilityCategory  "시설 카테고리" / "Facility categories"

## 6. 접근성 (A11y) 체크리스트

- [ ] **터치 타깃**: 모든 탭 가능 요소 ≥ 48dp(Android) / 44pt(iOS). 리스트 별 아이콘·필터 칩·FAB 포함.
- [ ] **대비**: 본문 텍스트 4.5:1↑, 큰 텍스트(18sp+/14sp bold) 3:1↑. 위 컬러 토큰은 M3 대비 기준 통과 값.
- [ ] **색 외 정보 전달**: 카테고리는 색 + 아이콘 + 라벨 3중. 단계 완료는 색 + 체크마크. 에러는 색 + 아이콘 + 텍스트.
- [ ] **스크린리더 라벨**: 마커("중앙도서관, 도서관, 상세 보기"), 아이콘 버튼(즐겨찾기 "즐겨찾기 추가/해제"), 지도/목록 토글 상태 announce.
- [ ] **동적 폰트**: sp 단위·`textScaleFactor` 대응, 최대 200%에서 레이아웃 깨짐 없음(스크롤 허용).
- [ ] **모션 감소**: `MediaQuery.disableAnimations` / reduce motion 시 전환 페이드 강등.
- [ ] **포커스 순서**: 상단→하단 논리 순서, 시트 오픈 시 포커스 이동, 닫을 때 복귀.
- [ ] **폼/검색 입력**: 검색 필드 `label` + hint, 클리어 버튼 접근명.
- [ ] **언어 속성**: ko/en 텍스트에 `Locale` 지정하여 스크린리더 발음 정확도 확보.
- [ ] **터치 외 입력**: 외부 키보드 Tab 이동 지원(기본 Flutter FocusTraversal).
- [ ] **오프라인/에러 상태**: 시각 배너 + 스크린리더 live region announce.

## 7. iOS HIG / Material 3 정합성

Flutter 단일 코드베이스에서 **의도적으로 통일할 부분**과 **플랫폼 분기할 부분**을 구분.

| 요소 | iOS(HIG) | Android(M3) | Campus-On 결정 |
|------|----------|-------------|----------------|
| 상단바 타이틀 | 중앙 정렬 | 좌측 정렬 | **분기**: `Platform` 별 정렬(Adaptive AppBar) |
| 하단 탭바 | Tab Bar(라벨+아이콘) | Navigation Bar(pill 인디케이터) | **분기**: `NavigationBar`(A) / `CupertinoTabBar`(iOS) 룩. 4탭 구성은 동일 |
| 뒤로가기 | 좌상단 chevron + edge swipe | 상단 arrow + 시스템 back/제스처 | **분기**: 기본 back 위젯. iOS edge-swipe 활성 |
| 모달/시트 | 하단 Sheet, Alert | Bottom Sheet, Dialog | **통일**: Draggable Bottom Sheet(지도 Peek), 확인창은 Adaptive Dialog |
| 버튼 | 텍스트/rounded | Filled/Tonal/Text | **통일**: M3 버튼 스타일 기준, 색만 토큰 |
| 아이콘 | SF Symbols | Material Symbols | **통일**: Material Symbols 1세트(비용·일관성). iOS도 동일 아이콘 |
| 스위치/컨트롤 | Cupertino | Material | **분기**: `.adaptive` 위젯(Switch/Radio) |
| 폰트 | SF Pro | Roboto/Noto | **통일**: Pretendard 번들 or 시스템 폴백 |
| 다크모드 | Dynamic | Material You | **통일**: 앱 자체 라이트/다크 토큰(디바이스 테마 추종) |

**원칙**: 브랜드 일관성이 중요한 컨텐츠(색·타이포·아이콘·컴포넌트 룩)는 **통일**, OS 관습이 강한 내비게이션 행동(탭바 룩, 뒤로가기, 스위치)은 **`.adaptive` 분기**. 구현 부담을 줄이기 위해 분기는 위 표 6항목으로 한정.

## 8. app-developer / api-integrator 인터페이스 힌트

> 실제 구현·필드 확정은 후속 단계. 아래는 화면이 요구하는 최소 데이터 계약(초안).

### 데이터 모델 (초안)

```
Facility {
  id: string                 // 고유키
  name_ko: string
  name_en: string
  category: enum { building, classroom, dining, library, amenity, etc }  // 시설 6종(emergency 아님)
  lat: double                // 카카오맵 마커
  lng: double
  address_ko: string?
  address_en: string?
  building_ko: string?       // "A동 2F" 등
  building_en: string?
  hours_ko: string?          // 운영시간(자유 텍스트, 한국어)
  hours_en: string?          // 운영시간(자유 텍스트, 영어)
  phone: string?
  description_ko: string?
  description_en: string?
  imageUrl: string?          // 없으면 카테고리 배너 폴백
  updatedAt: timestamp
}

AdminGuideCategory {
  id: enum { immigration, housing, living, health, school, emergency }
  title_ko / title_en: string
  summary_ko / summary_en: string
  icon: string               // 아이콘 키
  order: int
  itemCount: int             // 배지(파생값, 실패 시 숨김)
}

AdminGuideItem {
  id: string
  categoryId: enum(위 6종)
  title_ko / title_en: string
  summary_ko / summary_en: string        // 목록 1줄 요약
  overview_ko / overview_en: string?     // 섹션1
  checklist_ko / checklist_en: string[]  // 섹션2 준비물
  steps_ko / steps_en: string[]          // 섹션3 단계
  links: [{ label_ko, label_en, url }]   // 섹션4 링크
  relatedFacilityIds: string[]           // 섹션4 위치 → 지도 딥링크
  meta: { durationText?, difficulty? }    // 선택 메타
  status: enum { published, comingSoon }  // 자리표시자 상태
  updatedAt: timestamp
}

FavoriteRef {   // 로컬 전용(디바이스 저장, 서버 없음)
  type: enum { facility, guide }
  id: string
  savedAt: timestamp
}
```

### 화면별 데이터 요구 (요약)

| 화면 | 필요 데이터 | 페이지네이션/오프라인 |
|------|-------------|----------------------|
| S1 홈 | 카테고리 정적 + `itemCount`/시설 카운트(경량) | 카테고리 하드코딩, 카운트 실패 허용 |
| S2 지도 | `Facility[]`(id,name,category,lat,lng) 전체 or 뷰포트 | 캠퍼스 단위 소량 → 전체 로드 후 클라 필터 권장. 오프라인 캐시 권장 |
| S3 목록 | 위와 동일 + 거리(클라 계산) | 소량이면 무페이지네이션, 대비해 커서 페이징 여지 |
| S4 시설 상세 | `Facility` 단건 | 캐시 우선(오프라인 열람) |
| S5 가이드 카테고리 | `AdminGuideCategory[6]` | 정적에 가까움, 캐시 |
| S6 항목 목록 | `AdminGuideItem[]` where category | 카테고리당 소량 |
| S7 행정 상세 | `AdminGuideItem` 단건 + `relatedFacility` 조인 | 캐시 우선, `status=comingSoon` 처리 |
| S8 검색 | 시설+가이드 로컬 인덱스(name_ko/en, title) | 클라 검색(소량이면 서버 불필요), 디바운스 300ms |
| S9/S10 설정·즐겨찾기 | 로컬(SharedPreferences/Hive) | 완전 오프라인 |

### 오프라인/캐싱 UX 스코프 (api-integrator 전달)
- 데이터량이 캠퍼스 단위로 작으므로 **최초 로드 후 로컬 캐시(Hive/Isar) + 오프라인 배너** 전략 권장.
- 즐겨찾기·언어·최근검색은 서버 불필요, 전면 로컬.
- 카카오맵 타일은 오프라인 미지원 → 오프라인 시 지도 대신 목록/캐시 상세로 폴백 안내.
- Firestore 읽기 전용(MVP), 쓰기 없음. 이미지 없는 필드 다수 가정 → Partial 상태 UI 필수.

## 팀 핸드오프 노트 요약
