08 · 앱 구조

계층을 나눠서 데이터 출처를 바꿔도 화면은 그대로입니다

presentation
화면 12개 영역 — 홈, 지도, 강의실, 가이드, 학식, 학사일정, 검색, 설정 …
domain
엔티티 + 저장소 인터페이스 (Firebase를 모르는 순수 Dart)
data
Mock 저장소 ↔ Firestore 저장소를 플래그 하나로 교체
core
라우터, 테마 토큰, i18n, 레이아웃 유틸

상태 관리 Riverpod (autoDispose + 5분 TTL 캐시) · 라우팅 go_router · 하단 3탭 셸

도구 체인

  • 층별 안내 md 파서 → 시드 JSON
  • 도면 OCR 파이프라인
  • Firestore 시드 업로더
  • 관리자 시트 (clasp 배포)
  • 에뮬레이터 E2E 러너
